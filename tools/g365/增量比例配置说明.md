# G365PDF1 动态采集配置

主界面右侧常驻实时数据、HEX 和操作日志；左侧为可滚动的配置区，向下滚动可见设备读回和增量比例配置。

1. 启动 `g366_upper.py`，连接 IMU，确认寄存器可以实际读回。
2. 当前模式应为“增量导航 32-bit”，输出率应为 200 Hz；若不是增量模式，先用原有模式按钮切换。
3. 在“G365PDF1 增量比例（独立配置）”中点击“填入推荐值 4 / 8”。这一步只填入待写值。
4. 点击“应用比例（不保存Flash）”。当前高字节为 0 时，实际读回应为 `DLT_CTRL=0x0048`。程序只写 W1:0x12 低字节，保留高字节，逐项核对其他配置。
5. 需要掉电保持时，使用原有“保存当前全部可备份设置到 Flash”按钮。断电重连后再确认实际读回值。
6. 将 IMU 接回板子前，重新编译并烧录采用 `IMU_CAPTURE_DELTA_CTRL=0x0048` 的固件。新代码默认已改为该值，但电脑修改代码不等于板子已经升级。固件只解释数据，不会替你配置传感器。
7. 板子重新上电，保持静止直到启动标定完成并开始串口输出。采集工具的 DLT_CTRL 应为 `0x0048`，核对实际传感器后再勾选已确认。

G365PDF1 在 200 Hz、32 位输出下，角代码 0 的表示范围约为 ±49.65°/s，代码 4 约为 ±794.38°/s。该范围不代表扩大传感器物理量程。速度代码保持 8。面板显示的范围随设备输出率和待选角代码变化。

上位机按原始整数统计角增量饱和帧、速度增量饱和帧和错误 FLAG 帧；重新连接、成功应用配置/重新读取后重新计数。错误标志可能锁存，不能仅凭此计数判定具体故障原因。配置失败后会尝试恢复原比例并读取完整配置验证；无法确认时停用解码和写入，需要重新连接。

比例操作会清除上位机零偏标定。原有上位机标定仅适用于包含原始角速度的模式；板端 3 秒启动标定与它独立。应用比例不会自动保存 Flash，也不改变采样率、滤波器、波特率、DRDY 或 burst 模式。

原始 I/D/T/B 日志格式及保存路径不变。历史日志保留采集时的 B/JSON 比例；2026-10-03 的旧样本为 `0x0008`，不能按新比例重解释，更不能恢复削顶部分。新默认配置是待核对值，不是传感器自动读回。

寄存器写法参考 [Epson Python 驱动 `_config_dlt`](https://github.com/cubicleguy/py_esensorlib/blob/master/src/esensorlib/imu_fn.py)，范围采用 [G365PDF1 常量](https://github.com/cubicleguy/py_esensorlib/blob/master/src/esensorlib/model/mg365pdf1.py)。本次保留原上位机已有物理量显示系数，仅增加比例写入和原始整数饱和检测。
